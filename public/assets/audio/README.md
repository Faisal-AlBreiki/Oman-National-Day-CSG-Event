# ملفات الموسيقى

ضع ملفين بصيغة MP3 في هذا المجلد:

- `live.mp3` — موسيقى خلفية أثناء حالة LIVE. تعمل بتكرار مستمر وتتوقف عند إيقاف المسابقة أو بدء الكشف عن الفائزين.
- `win.mp3` — موسيقى إعلان الفائزين. تبدأ عند ضغط المنظم «إنهاء المسابقة وإعلان الفائزين»، تعمل مرة واحدة دون Loop، وتستمر حتى نهاية الملف. لا تتوقف بسبب تحديثات الشاشة الدورية؛ تتوقف فقط إذا أُغلق الصوت يدوياً أو بدأت جولة جديدة.

استبدل الملفين الموجودين مباشرة مع الحفاظ على الاسمين. اضغط زر «تفعيل الصوت» في شاشة العرض قبل بدء المسابقة؛ الزر يهيّئ مشغلات الصوت حتى يسمح المتصفح بالتشغيل لاحقاً.
